Retrieval-Augmented Generation (RAG) combines a retriever with a language model. Instead of relying only on what the model memorised during training, the system first searches an external knowledge base for passages relevant to the question, then gives those passages to the model as context. This reduces hallucinations, lets answers cite sources, and allows knowledge to be updated by changing documents rather than retraining the model.
A basic RAG pipeline has five steps: load documents, split them into chunks, embed each chunk into a vector, store vectors in an index, and at query time embed the question, retrieve the nearest chunks, and prompt the model with them.
